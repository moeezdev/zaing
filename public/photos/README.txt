# 📸 HOW TO ADD HIS PHOTOS TO THIS FOLDER:
===========================================

Simply drop your photos of him directly into this folder (/public/photos/)!

You can name them:
- photo1.jpg (or photo1.png / photo1.webp)
- photo2.jpg
- photo3.jpg
- photo4.jpg
- photo5.jpg
- photo6.jpg
... and so on!

Any image placed here will automatically show up in the website's Polaroid Memory Gallery and on Screen 3!
You can also upload photos directly on the live website using the "Add His Photo 📸" button anytime!
